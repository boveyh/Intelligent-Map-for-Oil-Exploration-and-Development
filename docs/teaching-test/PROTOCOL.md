## 材料与执行

- 公开站点首页、w4 演示；记录版本号/提交哈希与测试日期。
- 观察者使用 [空白 CSV](participants.csv)；每名真实受试者一行，`source` 必须是 `human`，`petroleum_background` 为 `no`。空白文件没有样例受试者。
- 桌面优先，另请至少一名用 375 px 左右手机测试；记录设备。暂不向参与者展示答案评分规则。
- 记录真实用时，不以 30—60 秒目标填空。观察者不解释术语或指挥点击；必须干预时记为卡点。

## 流程（每人约 8—12 分钟）

1. **浏览前**：问“你知道近邻分类如何做判断、不同量纲怎样影响距离吗？”保留原话作为定性背景，不把这两句当已验证的前测量表。
2. **首页**：首次保持默认暂停，请其解释图中输入、训练邻居、判断输出。主动播放一次；记录首页阅读秒数，并请其复述判断依据。记录“播放后是否理解”，不要自行补全答案。
3. **进入 w4**：受试者点击“开始引导”，按三步操作；记录完成时间和卡点。若 90 秒仍无法操作，允许继续，但不能写成 60 秒内完成。
4. **独立操作**：选择一个深度点，分别查看固定量纲缩放/井内标准化 KNN；记录当前点、两种距离、实际五票及传统分档。用截图或单点记录保存证据；不同点可能有不同答案。
5. **回答下列三个问题**，逐字记录，不提示答案。受试者总操作时间独立记录。
6. **访谈**：最难理解的一处、最容易误解的一句话、希望修改的控件。不要只记录正面意见。

## 三题与观察者评分（每题 0/1，必须附原话）

| 题目 | 得 1 分的必要证据 |
|---|---|
| Q1：这个深度为什么判成当前岩性？ | 指向该点 GR/DEN 和已标注训练邻居，说明实际多数票决定类别；不能只答“AI 算出来” |
| Q2：固定缩放和井内标准化前后，距离发生了什么，为什么？ | 根据当前面板/截图读出变化，并说明尺度/均值方差会改变距离；允许此点最近邻或类别不变，不要求背“标准化必然更准” |
| Q3：哪种岩性获得最多票，几票？这个票数是正确概率吗？ | 类别与当前五票一致，并说明票数份额不是经校准的正确概率；平票按实现固定类别顺序处理 |

三题全对为“本次任务理解通过”，不是长期学习效果。原始回答、截图与计分对应关系需保留。观察者可不知代码作者，减少期待偏差。
