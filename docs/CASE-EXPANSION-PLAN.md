## 3. 每个选题要守住的边界

- **g2**：按空间区域留出，不随机拆邻近采样点；组合异常只输出复核候选，不等于发现油气。协方差/相关背景来自可见参考样本，不能把测试异常标签用于拟合。
- **s1**：按整图划分；二维演示标明二维范围。候选掩膜来自实际模型推理，不能手绘或直接读取生成器断层标签。
- **d2**：输入只到当前时刻。改未来曲线不能改变当前判断；报告事件召回、误报次数/监测时长和告警时差，不用正常点占比造成的高准确率替代。
- **m2**：先说明迟到和组分的使用条件。首版区分构造的异常事件类型；仅凭合成气测不承诺真实油/气/水层定性，额外证据需求要列清楚。
- **w1 跨井**：区别于现有单井层界识别；匹配模型只看曲线与可计算特征，真实层位 ID 仅用于训练标签/事后评价。匹配评分的学习部分与对齐的层序规则分开解释。
- **c2**：图中流动是简化参考响应或概念示意，不冒充经验证 CFD。比较代理误差、可行方案命中及参考评价次数，不通过人为等待伪造加速。
- **co4**：首版是响应学习＋约束搜索，实际未实现强化学习时不称 RL。分别报告模型预测的可行性与参考模型检验的可行性，保留约束边界失败。
- **p3**：用虚拟型号和公开的合成规格说明排序机制；硬约束与学得偏好分开。不能把固定查表换个名称算成学习排序，也不提供真实现场弹型结论。
- **pr2**：按时间和井划分，未来未知协变量不能输入。措施特征参与预测不等于证明措施增产的因果效果；独立检验预测区间覆盖。
- **wo3**：只解释合成多臂内径所能支持的变形候选，不把它扩张为外壁腐蚀或全部损伤的可靠诊断。
- **e3**：未做的实验结果不可参与下一点选择；真实参考评价次数不得超过声明预算。重复不同种子，报告同预算性能及不利结果。
- **t1**：回放仅显示当前已到达的观测；未到达的传感器信息不可提前进入判断。首版给可疑区段，不以几何动画宣称实际定位精度或处置能力。
- **r5**：过程观测、已返回化验、待返回化验三者分开；模型拟合、区间标定、测试时间段分开。演示质量代理量与真实化验指标的关系须声明。

每例至少三类生成器敏感性设置：例如噪声、尺度/条件偏移、信号缺失/时延。类别不平衡、背景污染、薄层、弱断距、工况切换、未见配方等按本场景分别设计；不能用统一“噪声倍数”滑杆替代全部失效审计。

## 5. 统一实现与验收标准

### 案例表达

- 三部分围绕同一任务：作业困境 → 观测与标签 → 真实学习/推理 → 公平传统对照 → 输出差异 → 复核与失效边界。
- 一例一张独立场景概念图，统一当前暖白、岩层/钢材、青绿标记风格；空间模型、图像、地图、流程、真实数值图各有用途。
- 动画由实际合成观测、推理或方案驱动，默认可暂停；不生成装饰扫描或虚构模型特征图。
- 每例提供实际方法说明、三步可点击引导和 `trace-v1` 单点证据。选点形式按任务使用样点、像素、时刻、层段配对、候选方案或配方，不强制全部套深度曲线布局。

### 证据

- 实现真正的数据拟合或样本学习；明确哪一步是学习、哪一步是机理/规则/优化，不把网格搜索、DTW 或硬约束单独称作 ML。
- 开发阶段固定生成器、超参数和对照，再冻结训练/标定/测试配置；整井、整图、空间块、时间序列、配方/条件组按本任务隔离。
- 修改输入后证据通过真实推理路径更新；移除测试真值不改变推理。额外检查时间因果性、主动实验预算或路径约束等任务特有问题。
- 公开种子、模型/训练配置、测试分母、至少三类敏感性设置和失败档位。沿用既有负结果公开原则，不追求每例都显示学习胜出。
- 区间或概率只有在定义与标定依据明确时才如此命名；模型分数、票数和相似度按实际含义标注。

### 接入、主页与性能

- 沿用原 `case.json` 和 `demo/demo.js`，绑定表中已有 sceneId；原注册表、上传器和宿主文件保持兼容。
- 模型、图、样式和脚本自包含，浏览器本地实际推理；纯前端，不依赖云端算法接口或外部 CDN。包体目标约 1 MB 以内，硬上限仍服从原 6 MB 校验。
- 扩展构建器和检查工具的案例清单，不能靠放宽原场景验证、删除旧断言或改变上传协议来通过。
- 首页继续突出测井五主例，补 13 模块数量与入口索引；更多案例按模块展开。正文/模型按需加载，避免一上来铺二十三张大图或加载全部模型。
- 每批都做 375 px、键盘、实际交互、懒加载失败重试和公网资源测量。分别报告资源量与时间，不因资源量下降直接宣称打开更快。
- 各新包实际导入未修改原站并运行；旧包和原 firstbreak 反向导入继续回归。完成后才更新 Proposal、首页数量和发布说明。

### 当前约束

合成数据、概念图与真实观测始终区分；真实资料只有在具体文件、标签和许可核实后才接入。用户已决定不开展真人教学测试，本计划不再等待受试者，也不填教学通过率。新增数量是加分方向，不替代单例证据质量。

## 7. 首批两例的进一步设计

### 7.1 钻井 d2：多参数异常预警

- 原场景：`d2`，井下复杂事故前兆预警；拟案例 id：`d2-drilling-warning`。
- 核心问题：正常操作和异常发展都可能使单条曲线波动，模型能否利用多信号的组合及持续性减少误报？
- 智能方法：用其他合成井的标注时间窗训练加权逻辑回归；实际输入只使用当前及过去窗口。训练完成后冻结权重、标准化参数与默认告警规则。
- 输入拟包括进/返流量、池体积变化、压力等合成通道；具体变量与生成关系在开发阶段写明。模型特征以过去窗口内的差值、趋势和持续性为主，不输入生成器事件类型或隐藏状态。
- 对照：单信号阈值，以及多信号组合阈值规则。阈值在开发集确定，冻结后用同一批未见井测试。

#### 三部分怎样表达

| 部分 | 内容与视觉 |
|---|---|
| 背景 | 一幅独立的简化井筒/循环示意，说明传感器测到什么；以“同样的波动为何不能直接判异常”开场 |
| 流程 | 历史标注井 → 过去窗口 → 特征组合与学得权重 → 当前分数 → 持续性规则 → 待复核事件 |
| 演示 | 可暂停的事件回放；井筒流动和传感器标记随实际合成通道变化；选中某时刻，联动过去窗口、真实特征贡献及两种传统对照 |

演示至少包含正常操作、缓慢变化和传感器干扰等条件。动画不出现无数据依据的扫描、训练进度或自动处置动作；输出为需要复核的异常提示。

#### 必须留下的证据

1. 采用整井/完整事件划分，不能随机拆相邻时间点；输入不得使用未来曲线或居中平滑。
2. 自动检查：修改未来数据，当前及此前的预测保持不变；修改当前可观测输入，单点证据按同一推理路径更新。
3. 评价事件召回、误报事件数/监测时长、首次告警相对事件起点的时差；不以大量正常点造成的高准确率证明有效。
4. 至少三类敏感性设置：测量噪声、通道时延、正常操作/刻度漂移。公开全部种子、档位及冻结规则，不预设学习分支必胜。
5. 若出现事件前告警，只称为本合成生成器条件下的结果，不换算为实际井控能力或现场安全收益。

业务闭环参考 [SLB DrillOps predictive analytics 官方说明](https://www.slb.com/products-and-services/delivering-digital-at-scale/software/delfi/delfi-solutions/drillops/drillops-predictive-analytics)：其公开方案把多参数监测、模型与告警咨询联系起来。这是企业第一方产品说明，不是本项目效果证据；本项目拟用可解释小模型，不宣称复现其工业系统。

### 7.2 物探 s1：地震剖面断层智能识别

- 原场景：`s1`，地震断层自动解释；拟案例 id：`s1-seismic-fault`。
- 核心问题：亮暗变化、噪声和真正的地层错断都可能出现局部边缘；学习方法能否利用邻域连续性与错位信息筛出断层候选？
- 首版范围：小幅二维合成地震剖面，不把二维演示包装成完整三维地震解释。
- 智能方法：拟用浅层随机森林，输入实际局部图块的振幅变化、梯度和跨道连续性/错位特征，输出逐像素断层分数。训练可在离线构建工具中完成，树结构随案例打包，浏览器本地实际推理。
- 对照：梯度阈值、梯度加连通性规则；开发集选参数后冻结，在同一留出剖面比较。若开发试验显示森林没有稳定增益，保留结果并明确定位，不能靠手绘掩膜冒充模型输出。

#### 三部分怎样表达

| 部分 | 内容与视觉 |
|---|---|
| 背景 | 独立地层错断概念图与对应合成剖面，说明“断层在哪里”的作业对象；概念图不参与识别 |
| 流程 | 有标注训练剖面 → 提取实际局部图块 → 学习区分断层/干扰 → 输出分数与候选 → 人工复核 |
| 演示 | 原剖面、传统候选、模型候选联动；点击像素，放大实际邻域，显示实际特征、选定树的分支路径和全森林投票；阈值改变时叠加结果同步变化 |

播放动效用于逐步呈现图块、分支与投票，默认可暂停；候选掩膜必须来自推理。颜色条标“模型分数”，未做校准时不称正确概率。

#### 必须留下的证据

1. 按整幅剖面和生成种子隔离训练、开发、测试，不能从同幅图随机拆像素当独立泛化。
2. 点击点的分支路径、每棵树输出和总体投票与实际推理共用函数；零扰动输出一致，改输入图块后证据更新。
3. 报告精确率、召回、F1/IoU，并预先声明是否使用空间容差；固定留出图同时展示成功、误报和漏检。
4. 至少三类敏感性设置：噪声、断距/对比强度、反射连续性/干扰形态。不得只显示最清晰的大断层。
5. 首版合成物理与统计假设公开；训练图和测试图不得仅是同一底图的换色版本。

参考 [FaultSeg3D 作者项目](https://github.com/xinwucwp/faultSeg)：其公开方案使用成对合成地震/断层标签训练三维 CNN，并报告 PR/ROC 等评价。本站借鉴成对标注、分割对照和验证思路；拟用的二维随机森林是本站自己的简化设计。当前不下载、不复制其代码、权重、图像或成绩；如以后采用材料，需按具体许可处理。


## 8. 实现与验收回填

三批13例均已实现。22个自制包与1个原样例接入，全13模块覆盖。模型和背景图各自独立，复用的是数值函数、证据面板和布局，而不是同一任务换标题。

与拟方案的明确差异：跨井首版以给定层段边界计算特征并做单调对齐，对照GR层段动态对齐和同序号关联，不称全曲线DTW或同深度关联；地震对照为梯度及错位规则，没有实现三维分割；固井使用效率森林和线性代理，同样不称CFD；产量对照为最近值与递减模型，没有单列滚动均值分数；地化提供采样网格和组合距离，未另绘背景椭圆。固定方案/全开没有在所有优化例中另报汇总分，不应把计划列出的全部对照都视为已完成。
