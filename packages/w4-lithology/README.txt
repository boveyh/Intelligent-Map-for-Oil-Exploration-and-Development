岩性识别 · 示范案例包
========================================

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹整个拖进弹窗；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到对应场景，三个 tab 立即出现。

文件清单
--------
  case.json        清单：元信息 + 专业背景 + 案例流程（必需）
  demo/demo.js     可运行示范（模块模式，挂进 Shadow DOM）
  README.txt       本文件

示范内容
--------
合成数据交互实验。先切换四种方法，比较同一合成测试井的分类。拖动深度滑杆或点选岩性柱，查看该点实际参考的五个近邻、距离和投票；点击“下一个方法分歧点”定位 GR 与 KNN 意见不同的位置。再改变井间漂移或训练井数，观察依据与结果怎样变化。 测试井不进入训练样本；井内标准化使用整条无标签曲线，不是随钻在线预测。

说明
----
纯前端、无外部依赖、无网络请求；所有数据在浏览器里按固定随机种子合成，
交互指标由页面实时计算；背景和流程中的静态对照数值由 tools/test-*.js 复算。
场景图为 AI 生成的静态概念模型，用于解释空间关系，不参与算法计算。
