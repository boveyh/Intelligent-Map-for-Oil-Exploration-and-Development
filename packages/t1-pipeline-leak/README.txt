管道泄漏识别与区段定位 · 示范案例包
========================================

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹整个拖进弹窗；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到对应场景，三个 tab 立即出现。

文件清单
--------
  case.json        清单：元信息 + 专业背景 + 案例流程（必需）
  demo/demo.js     可运行示范（模块模式，挂进 Shadow DOM）
  README.txt       本文件

示范内容
--------
合成数据交互实验。先用三步引导选中一个具体对象，查看 事件随机森林＋到达时差回归 的真实中间计算，再切换 流量平衡阈值、流量与压力组合规则。传播速度与压力响应为合成假设；未验证实际管道定位精度。 传播速度与压力响应为合成假设；未验证实际管道定位精度。

说明
----
纯前端、无外部依赖、无网络请求；所有数据在浏览器里按固定随机种子合成，
交互指标由页面实时计算；背景和流程中的静态对照数值由 tools/test-*.js 复算。
场景图为 AI 生成的静态概念模型，用于解释空间关系，不参与算法计算。
