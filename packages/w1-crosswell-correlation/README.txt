跨井地层智能对比 · 示范案例包
========================================

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹整个拖进弹窗；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到对应场景，三个 tab 立即出现。

文件清单
--------
  case.json        清单：元信息 + 专业背景 + 案例流程（必需）
  demo/demo.js     可运行示范（模块模式，挂进 Shadow DOM）
  README.txt       本文件

示范内容
--------
合成数据交互实验。先用三步引导选中一个具体对象，查看 学习匹配评分＋保持层序的对齐 的真实中间计算，再切换 同序号关联、GR 特征动态对齐。候选层段边界在本例中已提供；真实层位 ID 只用于训练标签与事后匹配评价。 候选层段边界在本例中已提供；真实层位 ID 只用于训练标签与事后匹配评价。

说明
----
纯前端、无外部依赖、无网络请求；所有数据在浏览器里按固定随机种子合成，
交互指标由页面实时计算；背景和流程中的静态对照数值由 tools/test-*.js 复算。
场景图为 AI 生成的静态概念模型，用于解释空间关系，不参与算法计算。
