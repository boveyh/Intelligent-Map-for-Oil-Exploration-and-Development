储层参数智能解释 · 示范案例包
========================================

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹整个拖进弹窗；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到对应场景，三个 tab 立即出现。

文件清单
--------
  case.json        清单：元信息 + 专业背景 + 案例流程（必需）
  demo/demo.js     可运行示范（模块模式，挂进 Shadow DOM）
  README.txt       本文件

示范内容
--------
拖动"建模井数"看学习曲线，切换"按井 / 随机划分"看 R² 怎么被划分方式骗出来 —— 右边的近邻同井率是关键读数。

说明
----
纯前端、无外部依赖、无网络请求；所有数据在浏览器里按固定随机种子合成，
指标由页面实时计算，不含预置结果。
